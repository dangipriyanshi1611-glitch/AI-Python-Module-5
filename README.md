# 🎯 Quiz Generator

## Module 5 – AI Tools & Mini Project

## 📌 Project Overview

Quiz Generator is a simple Python-based mini project that allows
users to take multiple-choice quizzes on different computer-related
topics.

The user can select a topic such as Python, Machine Learning, or
Artificial Intelligence. The program displays questions with four
options and checks the user's answers.

At the end of the quiz, the program calculates the user's score and
percentage.

---

## 🎯 Objective

The objective of this project is to create a simple and interactive
quiz application using Python.

This project helps in understanding basic Python programming concepts
such as:

- Lists
- Dictionaries
- Functions
- Loops
- Conditional statements
- User input
- Randomization
- Score calculation

---

## ✨ Features

- Simple command-line interface
- Multiple quiz topics
- Multiple-choice questions
- Four options for each question
- Automatic answer checking
- Automatic score calculation
- Percentage calculation
- Randomized question order
- Performance message based on score
- Beginner-friendly Python code

---

## 📚 Available Quiz Topics

The project currently includes:

1. Python
2. Machine Learning
3. Artificial Intelligence
